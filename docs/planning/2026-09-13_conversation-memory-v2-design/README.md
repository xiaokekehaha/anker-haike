## 已确定的方向

- PostgreSQL 保存原始有序问答与动作，LangGraph checkpoint 保存当前业务状态；上下文与摘要是派生信息。
- 当前不接 Mem0，不做跨会话个人记忆。未来可在相关历史检索处增设适配，不占当前主链路。
- 所有自然语言入口先做语义理解；固定规则负责操作限制与状态校验，回复围绕本轮意图生成。
- 同会话支持多个问题及设备指代，纠正可追溯；历史风险约束相关设备的操作，不阻止正常对话。
- 等待卡片保存在业务 pending 中，单轮图结束；直接替换当前图，不保留旧 interrupt 执行路径。
- 用户已明确历史可清理、无需兼容。实施时清理历史会话，前后端一次统一切换；不做双协议、旧数据迁移或按会话分配引擎。
- 不用“已出摘要”替代“人工已接入”；当前未接外部人工服务时只能显示已整理摘要/人工入口。
