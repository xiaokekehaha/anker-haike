# 新版会话交付记录

2026-09-13，按用户授权完成清理、开发与本机 Compose 部署。执行范围以 step-back.md 为准。

## 已实现

- 一条自然语言入口：接收有序原始问答 → 理解本轮意图 → 校验问题状态变化 → 按需调用业务能力 → 保存并回答。删除旧 rediagnose、重复 intake/human_request 节点及旧动作账本 API。
- 用户与助手的原话、图片引用、动作和卡片保留来源、时间戳与 seq；近期完整问答进入模型上下文，较早原文可回查。派生摘要可失效重建，明确纠正不改写历史气泡。
- 问题与设备分开保存：切换、恢复、纠正及风险不再靠拼接全会话文本；回顾、解释和纠正澄清不会重复转人工。
- 待办卡片有身份与输入令牌；解释保留待办，反馈幂等。凭证可替换、确认或跳过，保持来源。
- 人工状态按真实能力表达：当前只能准备摘要，没有真实转接回执，不能宣称已经接单。
- 输入账本、发布 checkpoint 和事件水位协同处理重试、取消、断线和刷新。单 worker 部署。
- 不引入 Mem0；使用 PostgreSQL 原始记录、问题状态及可重建的上下文摘要。
