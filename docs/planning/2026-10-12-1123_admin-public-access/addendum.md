# 部署复核

- 用户明确要求管理页面也能公网访问，替换之前禁用公网 /admin 的策略。管理员使用独立账号与密码，viewer 无管理权限。
- 为使浏览器在访客登录后提示管理员登录，使用独立认证区域 haike-admin；普通路径也接受管理员凭据，用于加载共享模块。
- L3 操作依赖代理认证身份，因此对管理路径覆盖 X-Authenticated-User，并清理普通请求中的该头；不依赖客户端自报身份。
- AWS 会话过期与网络出口变化已修复；使用用户再次授权的已有 AWS 凭据重新登录，仅替换 SSH 来源 /32，不增加实例或开放额外端口。
- 代理配置已验证后部署并重载，云端仅保存认证散列，本机 .env 保存管理员密码；访客密码未轮换。
- 只读公网检查覆盖页面、深链、共享模块和管理 API；不执行案件审批、标注、模型或知识库操作。
