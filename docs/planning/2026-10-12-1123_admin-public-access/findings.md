# 核对结果

- 现有 Caddy 对 /admin 与 /admin/* 返回 403；用户现要求开放管理访问。
- 管理观测接口没有应用层认证，要求置于认证代理之后。
- L3 操作从 X-Authenticated-User 取得管理员身份；非开发环境缺失时返回 403。
- Vite 同源代理 /admin/api 到本机 8000，管理页面使用 /src 与共享前端模块；管理员凭据也需能访问普通路径加载静态资源。
- 本机 /admin/ 返回 200，应用无需构建或代码修改。
- 管理端使用独立 Basic Auth 认证区域，使浏览器能在已登录 viewer 后提示管理员账号；普通区域同时接受 viewer 与 admin。
- 转发前移除客户端身份头，管理认证成功后再写入代理验证的账号；基础认证密码不转发给本机服务。
- 实际公网验证：admin 访问管理页面与只读接口 200，viewer 与未认证用户 401；挑战头分别为 haike / haike-admin。
- 编码路径、点路径和重复斜杠仍匹配管理认证范围；模拟上游验证管理员身份覆盖及口令去除。
- 当前运维网络出口为 103.167.140.181，SSH 入站恢复为该 /32；实例及端口范围未增加。
