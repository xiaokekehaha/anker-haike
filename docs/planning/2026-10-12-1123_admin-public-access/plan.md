# 管理端公网访问

目标：按用户要求开放现有 AWS HTTPS 入口下的 /admin 页面与 /admin/api 接口。

约束：使用独立管理员凭据，保留访客入口；不新增云资源、不修改应用数据、不调用真实模型或知识库。真实密码只保存在本机 deploy/tunnel/.env，云端 /etc/haike/haike.env 仅保存认证散列。

实施：

1. 核对管理端 API 的认证与身份来源。
2. 配置管理路径独立认证，普通路径兼容管理员访问前端资源；清除客户端伪造的 X-Authenticated-User，管理请求写入代理已认证身份。
3. 生成管理员密码与散列，准备配置解析和 HTTP 角色访问矩阵检查。
4. 部署 Caddy 配置并重载，在公网验证管理员页面、只读接口与访客权限。

验收：未认证无法访问；管理员可访问 /admin、管理深链和 /admin/api；viewer 无管理权限，仍能访问首页；HTTPS 校验通过，身份头不能由访客伪造。

开发后不修改本文件；复评写 addendum.md。
