## 5. 演示脚本（决赛）
1. A4 查物流（30 s）：展示意图直达与来源。
2. A9 看图（1 min）：清晰图直接定位命中计划；模糊图补拍卡。
3. A1→A5（3 min）：排障两步未解 → 方案卡（条款引用）→ 确认 → 回执 → 案件跟踪 → 评分。
4. A6 越权（2 min）：UK 购 DE 用 → 诚实说明 → 管理台审批 → 自动执行。切换到管理台展示门检查项与政策条件表。
5. A8 接稳（1.5 min）：三轮情绪升温 → 策略变化可见 → complaint_risk 置顶。
6. A7 多诉求（1 min）：顺序告知与自动接续。
7. 管理台 Dashboard（30 s）：托管率 / 意图 / NSS / 越权 0。
全程回放包兜底；模拟后端故障注入按需展示降级。
