# 用户进度与业务状态

进度展示也必须遵守对象归属：排障、查询、办理使用各自的阶段；案件状态仅来自当前问题。前端不根据步骤位置推断前面所有动作都已完成。

`frontend/src/state/progress.ts` 统一进度条、最近会话和案件状态标签的读取。服务信息、方案确认、人工审核、失败重试和结案展示对应阶段；查询显示查询路径。最近会话记录当前问题的案件状态，切换到无案件问题时清除旧状态。
