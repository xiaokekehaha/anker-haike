# 官方 63 案继续测试与中文独立判断

## 目标

重新执行官方 T1–T63，依据原始诉求、实际回答、官方资料及一般故障诊断常识逐案判断，输出有数据支撑的汇总与中文歧义记录。

## 方法

1. 复核官方来源、既有事前判据、服务健康及运行代码指纹；保留他人改动。
2. 63 案各新建会话，沿用上一轮固定策略：原始正文及附件首次发送；动作卡仅模拟未解决；型号仅在明确追问时从官方产品列补充；未知事实、材料、方案确认与真实人工边界停止。
3. 独立复跑已固定的 18 个分支与 5 个重复首轮，分别计分，不加入 63 案主分母。
4. 只读补采实际查询、发布状态与案件结果；保存所有异常，不以重跑覆盖失败。
5. 按原意对象、资料适用性、业务与安全边界、下一步可反馈、状态承诺一致五项判断。常识用于检查逻辑，特定型号功能、保修与配件兼容结论需要官方证据；无法确定的保留待核。
6. 冻结逐案判断后计算首轮、已观察路径、分支、重复样本及耗时数据；输出中文歧义台账，记录原句、不同解释、当前裁定、证据与待补事实。

## 约束

- 本轮为用户授权的真实 HTTP 服务评测，不通过单元测试调用真实模型。
- 不修改业务实现、官方资料或历史报告，不提交或发布。
- 模拟未解决不代表设备实际操作，人工入队不代表已办理，不计算现实解决率。
- 评分者看过历史，不能称盲测；不同轮次比例只有同口径才能比较，单轮差异不能证明稳定改善。
- plan.md 开始执行后冻结；变化与勘误写 addendum.md。

## 验收

63 案均有实际运行证据和中文结论；补充分支及重复样本单独报告；汇总可由冻结判断与原始证据重算；所有识别出的歧义有中文记录。
