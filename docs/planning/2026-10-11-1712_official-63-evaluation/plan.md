# 官方63案例续测与中文归因

## 目标
在当前本地运行服务新建63个独立会话，逐案审查实际输出，保存中文详细过程、原始证据、分类判断与整体汇总。

## 方法
1. 核对代码与容器指纹、服务健康、官方输入与附件；复用已完整阅读的真实HTTP驱动。
2. T1–T63首轮发送官方原文原附件；明确追问型号时仅补官方产品列；动作卡统一模拟未解决，问题、材料、确认与人工边界停止，不编造未知事实。
3. 所有异常保留；只读补采会话、检索、图片和执行证据。按本轮实际输出独立评分，历史仅用于复用一致的译文与完成后的对照。
4. 区分系统流程、agent能力与权限边界、知识未命中/已命中未采用/资料缺口、意图对象、图片识别与图片不可证明、官方口径以及测试覆盖限制。每案主分类互斥，并存标签可重叠。
5. 通用知识用于逻辑核验，型号功能和政策需官方证据；不确定内容记待核。给出首轮和已观察路径两套评分，不把合理澄清或转人工判为失败，不声称设备实际解决率。
6. 保存63份中文逐轮记录、机器可读裁定、汇总和完整性校验；必要补测单列分母。

## 范围
用户授权的真实服务评测，不是单元测试。只新增本轮记录，不修改业务代码、知识库或其他会话文件，不提交、不发布。plan.md执行后冻结，调整写addendum.md。
