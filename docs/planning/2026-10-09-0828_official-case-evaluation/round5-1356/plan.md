# 新增十单测评计划

目标：从官方工单中选十个不与 T1/T9/T11/T12/T13/T45/T51/T55 重复的案例，测当前系统回答与处理方向是否符合官方事实及知识。

1. 覆盖物流、多个扫地机型号、吸奶器、安防摄像头、附件与情绪场景，按差异挑选而非随机抽样。
2. 运行前保存来源 sheet/行号、原文、相关订单与Q&A，固定每单正确/部分/错误标准。
3. 首封用原文及原附件；精确型号匹配后可选择产品。故障卡统一反馈未解决，正常解释类反馈解决。缺少真实材料、客户确认、评分或人工交接时停止，不模拟人工处理。
4. 核对最终答复、每个步骤及实际状态；首测结论保留，必要复测单独记录，不替换失败。
5. 只写测评文档，不改应用代码或提交Git。延续原计划，复评写addendum及流水文件。
