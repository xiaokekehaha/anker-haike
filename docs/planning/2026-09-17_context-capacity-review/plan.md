# 上下文容量与验收核查

## 目标

回答当前模型上下文容量、应用预算和裁剪机制、已有测试与产品预期，以及应采用的管理方式。以 d524 会话的预算超限为具体案例，不修改运行代码或发起付费模型请求。

## 步骤

1. 核对模型路由、预算计算、上下文构造和摘要实现。
2. 核对当前使用模型的厂商官方容量说明，区分本地声明与已验证事实。
3. 完整阅读并运行相关离线测试，核对已有验收文档与覆盖缺口。
4. 给出分阶段预算、按任务投影、降级方式和可检验验收建议。

## 交付

findings.md 保存证据与建议，progress.md 记录检查结果；答复明确哪些能力已经验证、哪些只是建议目标。
