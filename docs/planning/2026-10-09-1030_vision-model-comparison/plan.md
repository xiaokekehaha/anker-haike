# 图片模型与 GLM-OCR 评测

目标：回答当前项目图片识别中 DeepSeek 是否优于 GLM，并评价智谱截图中的模型在本项目的适用性。

范围：核对官方模型定位与 API；复核历史评分和样本；固定现有图片及评分标准，实际对比 DeepSeek、Qwen-VL、GLM 视觉模型；对文字图片补充 GLM-OCR 实测。记录准确率、编造信息、延迟与失败原因。图片生成、语音识别及合成只评估用途，除非有相关样本，不虚构质量评分。

约束：不修改业务路由或密钥，不提交代码；不触碰其他会话改动。密钥仅从 `.env` 加载，日志与报告脱敏。真实模型调用属于用户授权的评测，不混入单元测试。优先复用现有评测入口，新增适配放独立临时脚本或评测目录。

方法：区分完整业务流程分数和模型单次读图能力；相同任务使用相同图片与提示词。至少两遍，关键反例追加复核；记录小样本、合成图、正在变化的工作区及历史价格等限制。

交付：独立报告、脱敏原始结果、推荐与结论边界。开发开始后本文件保持原样，调整写 addendum.md。
