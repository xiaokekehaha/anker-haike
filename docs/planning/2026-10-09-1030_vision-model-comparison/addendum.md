# 评测口径补充

2026-10-09 10:36：现有工作区中的图片业务代码正在被其他会话修改，旧评分还包含订单号宽松匹配与主备裁决问题。为隔离这些因素，主要比较改为相同图片、相同任务提示词的单次 API 输出；业务流程历史结果单独列出。保留现有配置参数（关闭思考），关闭重试与备用切换。

样本以项目 10 张官方附件为主，补充旧套件的小字铭牌。模型不接收工单文字和标准答案。图片理解和文字转录分别评分；GLM-OCR 只参加文字转录。至少两次请求/图片/模型，先用少量样本校验接口与响应格式。

首轮 T45 全文转录在 DeepSeek 和 GLM-4.6V 上出现输出到达上限；为区分全文转录与本项目实际使用的字段抽取，补充全部 5 张凭证的统一四字段抽取任务，不只重跑失败样本。补充三张铭牌的相同九宫格裁剪（使用预先已知右下格），只衡量裁剪带来的读字改善，不把它当作自动定位成功率。

新增官方支持图片的 GLM-5.3-Flash。官网不允许关闭思考，因此使用 enabled、推荐 temperature=1/top_p=0.95、max_tokens=8192；原有三家按配置关闭思考或默认非思考、temperature=0、max_tokens=2048。不把这种不同推理预算下的差异解读为严格同算力排名。
