# AWS 本机服务公网接入方案

目标：服务继续运行在本机，利用 AWS 云服务器提供外部可访问的 HTTPS 入口。

用户约束：没有域名；AWS 控制台已能登录；尚未确认所有区域的既有实例。

工作范围：核对无域名 HTTPS、EC2 规格和费用，准备代理配置与隧道步骤，形成具体的资源创建确认项。

实施拓扑：访问者 → AWS 固定公网 IP 的 HTTPS 代理 → 云服务器回环端口 15173 → 本机主动建立的 SSH 反向隧道 → 127.0.0.1:5173 → 本机 8000 API。

执行顺序：

1. 核对现有项目入口、流式响应和管理端访问范围。
2. 核对 IP 地址证书、自动续期和云资源费用。
3. 准备最小代理配置、SSH 命令和验证步骤。
4. 向用户展示具体资源、费用和公网访问范围；取得资源创建批准后再部署。

验收：提供明确的 HTTPS 地址；未认证请求受阻；前端和健康检查可访问；SSE 持续流式返回；本机与云端数据库端口无需公网开放。

开发开始后此文件不修改；补充和勘误写入 addendum.md。
