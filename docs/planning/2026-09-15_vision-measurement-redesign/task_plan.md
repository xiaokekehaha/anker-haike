# 看图能力重构（第一性原理规划）

## 目标
把 `diagnose.vision` 从「一次模型调用」重构为「一次可信的测量」，使赛题「看图」难点的评审口径（识别后的信息提取、精准锁定故障位置）有结构性保障，而不是靠模型碰运气。

## 阶段
- [x] 核实工作树现状（vision.py / localization.py / vision_vocab.yaml / models.yaml / graph 路由 / 前端卡片 / 评测集 / 图片素材）
- [x] 从第一性原理推导目标形态，产出 [plan.md](plan.md)
- [x] 阶段 0：建立可验证性（13 条字段级用例 + 七个指标族 + 报告聚合表；基线见 reports/bakeoff-baseline）
- [x] 阶段 1：让测量不撒谎（L0 预处理、不可辨态、砍字段、去 confidence 阈值、L3 裁剪复看 + 交叉核对、链序主位）
- [x] 阶段 2：让测量不被污染（图文分路 + 专用系统提示、describe-first、冲突检测移到代码层；无幻觉率三家均达 100%）
- [x] 阶段 3：让可信度外生（L1 像素门控 + 阈值标定 + usable 改 AND；门控样本实测 0 token）
- [x] 阶段 4：隐式确认、预赛材料看图章节、demo 脚本（真实照片仍缺）
- [x] 阶段 5：demo 脚本与回归（42 个看图用例全绿）

## 决策
- 规划阶段不改代码、不改配置。
- 排序按「静默错误代价」而非工作量：误测 > 漏测，因为误测不可察觉。
- 字段只减不增；每加一个字段必须先回答「谁读它」。
- 不训练模型、不引入检测器、不做参考图对比（赛期内证据不足）。

## 阻塞
- **无任何真实故障照片**（仓库与本地均无，`data/bakeoff-images/` 不存在）。卡住真实纹理识别率验证与链序最终裁决。建议自拍 + 公开图并行，不等主办方。
