# 细化与复核

- 本轮直接实施用户已认可的链路B方向；新语义应有独立配置，不能把原有grade硬过滤视为充分性补救。
- 具体配置复用query_rewrite.enabled控制完整补救单元：开启后有候选则自动做充分性评估；grade.enabled可独立做观测。两者默认仍false，避免未经真实金标验证就上线模型行为。旧grade硬过滤已移除，不保留两套过滤语义。
- candidate_k=15、final_k=12、context_chars=5000、item_chars=800分别控制候选与最终文本；首轮/二轮及来源交错选择，不比较跨来源分值。保留反证代表，评分不充当删除依据。
- 最终上下文和引用白名单使用同一选中集合；修正父块窗口只截开头的问题，围绕命中子块选窗口。
- query_rewrite已有剩余时间门槛仍为有限预算保障；当前默认关闭模型增强。本轮不调整全局会话deadline或运行真实模型实验。
- 复核补充：评分先按诊断最终预算选择正文，再收紧评分预算，不能重新打开已经裁掉的原文；空正文不占候选选择名额。
- 知识库适配器禁用时的故障卡也统一预算，保留context_selected与synthesize降级追踪。guide之后的计划引用与诊断输入分开验收。
- 六份可执行评测预设迁移新配置结构，历史release/report不修改。新增非扫地机同义扩展隔离和反证不可单独判充分的测试。
