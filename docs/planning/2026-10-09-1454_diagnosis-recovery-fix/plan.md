# 排障恢复与人工交接修复

目标：修复随机十单发现的安全否定、检索裁剪、待确认方案及人工出口问题；采用通用机制，不按工单编号特判。

1. 完整读取拟修改模块，保留前轮及其他会话改动，建立失败回归。
2. 修复否定观察的规则边界，保留真实危险和转折句拦截。
3. 对被预算裁剪的候选提供有界恢复；保留适用性检查及既有正常路径，不以增大条数作为唯一修复。
4. 将有依据的待确认候选送入澄清，回答后重新评估，限制重复追问。
5. 将需要人工的通用摘要可靠提交到案件队列，提交成功才显示已交接，不自动执行服务单。
6. 运行相关测试和make lint，记录验证范围及运行容器更新情况；不提交Git。
