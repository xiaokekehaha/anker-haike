# 多轮问题复现与完整会话记录

## 目标与范围

按用户反馈复现平地持续报错、充电盒灯不亮、连续噪声和 T48 补型号后检索目标丢失四个分支，交付完整用户输入、系统文本、卡片、实际检索问题及复现结论。

## 执行方案

1. 阅读原评测分支、执行器和接口，确定官方首轮、模拟后续输入与附件。
2. 对当前运行服务新建独立会话，使用真实服务重跑四个分支；记录服务版本、时间、会话 ID 和原始响应。
3. 将已有评测与本次重跑分开标注，核对用户指出的具体症状；记录未复现和输出差异。
4. 整理可直接阅读的完整会话文档，保留原始 JSON 以供追踪。

## 约束

- 本次只复现和整理记录，不修改业务实现，不提交，不发布。
- 真实服务复现不是单元测试；不通过 tests 导入启用真实模型。
- 不输出或保存密钥，不覆盖其他会话已存在的未跟踪文件。
- diagnosing-bugs 的假设、修复、回归阶段不在本次用户请求范围，跳过；保留复现证据。
