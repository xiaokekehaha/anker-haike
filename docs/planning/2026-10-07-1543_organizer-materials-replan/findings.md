## 2. 业务 SOP（docx 图片转写）

文字规则（黄框，左侧被裁，按可见部分转写）：

1. 物流问题：物流轨迹**未显示送达**且客户表示**未收到**，可以补发；**显示送达**的包裹不再补发。
2. 故障问题：提供完对应故障排查后问题仍存在，可给**质保期内**产品换货处理。
3. 换货 / 退款必须提供的质保信息：订单 / 购买凭证、发货地址、相关视频 / 图片证明、产品 SN（故障问题需提供）。

流程图：

```
 ...Y --> [AI 检索知识并生成回复] --> <问题是否解决> --Y--> (结束对话并发送满意度调查)
                ^                          |
                |                          N
                |                          v
                +-----------N------- <确认是否进入换货/退款流程>
                                           |
                                           Y
                                           v
                                    <订单质保判断>
                    +----------------------+----------------------+
                 查不到                  质保期内               质保期外
                    v                      v                      v
             [核实购买商家名]          [寄修/补单]      [告知过质保信息并委婉拒绝售后]
                    v                      ^
             <判断是否授权经销> --Y--------+
                    |
                    N
                    v
         [引导客户自行联系商家售后]
```

图最左侧 `Y` 之前的节点不可见（推测为「是否售后问题 / 意图识别」），需向主办方要原图。

工具约束（原文）：工单系统、订单系统**均不提供接口**；换货、退款节点涉及订单系统操作时，参赛者自建工具，让 Agent 把换货单 / 退款单信息通过工具传入，**最终在工具中设置转人工节点**。

经销商规则：下单 country **精准匹配** + seller **模糊匹配** → 授权经销商，否则非授权。

## 4. 客诉工单 sheet

字段：产品线、产品名、客户首封邮件内容、订单号、SKU、附件、咨询场景。

- 63 单。咨询场景只有两类标签：Shipping inquiry 11、Troubleshooting/Product usage 52（docx 提到的 product inquiry 没有单独标签，混在后者里）。
- 产品：S1 Pro 扫地机 13、X10 Pro 14、E25 8、E28 5、C10 3、Omni C20 3、eufy cleaner 1；S1 Pro 吸奶器 12；SoloCam S340 3、security camera 1。
- 语言：英语为主；荷兰语约 7、法语 1、德语 1、西班牙语 1。
- 首封消息三种格式：
  - App 结构化反馈（约 30 单）：`Product Name / Product PN / Product SN / Problem Type / Problem Code / Problem Push / Problem Description / Problem Upload Images`，也有荷兰语、法语、德语、西班牙语字段名版本。
  - anker.com RMA 表单（约 6 单）：`Source: amazon / Order No / Product Name / Problem Description / Prodcut SN / Country / Submit Date`。
  - 自由邮件。
- 错误码：扫地机数字码（3212、4090、2310、6011、6013、6063、7002、2111、3021、5116）与 S1 Pro 字母码（EB1L、EB03、E41、E53、E23、E4、E5A）。除 5116 外都能在 Q&A 标题里精确命中（KB 只有 5112）。
- 订单号：约 2/3 的工单为 `/`（未提供），1 单标注「用户未提供需询问」，1 单标注「Reseller（提供 12 个月质保）」。
- 附件：
  - 内嵌 10 张图。5 张是购买凭证：UK 发票、Aeroflow 订单邮件、Amazon 订单截图、AnkerDirect 发票、Amazon 订单摘要。4 张是设备照：机器人亮红灯、基站摆放位置、S1 Pro 脱落的塑料件、E28 机身。1 张是吸奶器 Hub 灯态，用户问 "what does this green light mean"，图中外壳还有裂纹。
  - 正文里的 S3 图片链接已脱敏，无法访问。
- 情绪：4–5 单辱骂或强烈不满（"You're fucking cameras suck"、"This app is shit"），1 单 "exclusive pumper"（紧急），1 单安全相关（"heating part also burned me"）。
- 多诉求：T9（预售未发 + 想改买其他产品）、T41（烘干故障 + 等待新插头寄送）、T59（两台 S340 想换成 C20）。
