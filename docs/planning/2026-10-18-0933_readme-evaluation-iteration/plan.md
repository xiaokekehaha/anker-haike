# README 评测指标与 AI Native 迭代说明

## 目标与范围

依据最新可核验的已有评测数据，补充 README 的意图识别、案例效果等指标，并说明项目以 AI 参与分析、开发、评测和复测的迭代做法。

## 实施顺序

1. 按运行时间、样本范围、配置与评测规则筛选最新全量报告，检查原始结果和局部复测。
2. 复算指标分子、分母，区分自动标签匹配、流程终点、逐案语义质量与模型可用性。
3. 读取迭代相关设计、实现与修复记录，明确已有机制与未来方向。
4. 更新 README，保留来源、日期、定义及适用边界，验证链接与差异。

## 边界

- 不重跑真实模型，不生成新的评测成绩。
- 不混用不同配置或局部复测数据；不将单测通过率称为业务准确率。
- 不公开原始客户信息或忽略的运行 JSON。
- 保留架构、方案、技术选型前置及不展示演示地址的要求。
- 本轮未收到新的提交、推送请求，先完成可审阅文档修改。
