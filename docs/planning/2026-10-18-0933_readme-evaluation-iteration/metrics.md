严格匹配复用原报告的终点字符串相等定义；多终点顺序不同也不属于该指标的完全相等，不改写为新的集合覆盖率。

## 结论边界

该集合同时用于开发及评测，不是独立留出集或比赛官方评分。意图接受细分类归并与标注备选；SOP 允许与驱动策略对应的替代终点，可能把异常兜底算通过，也可能把合理文字追问算失败。限定违规检查只覆盖规则列明的禁止行为，不能推广为零幻觉。耗时是模拟多轮案例处理耗时，不是首字延迟或真实人工等待时间。当前版本整体回答正确率、真实解决率与独立托管率没有由本轮数据建立。
