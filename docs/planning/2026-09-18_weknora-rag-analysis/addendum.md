# 复核与勘误

- 初步观察到数据库metadata完整；进一步解析最终模型请求，确认Quick Answer转换层遗漏knowledge_metadata。因此最终分析不把错类简单归因于模型忽略metadata。
- 区分RRF、模型rerank和内容去重。本轮rerank阶段存在但跳过，10条变4条发生在Merge去重。
- 区分主回答消息完成约6秒与SSE连接约9.24秒；连接在消息完成后仍等待标题事件。
- 核对候选数量、父块回缩和跨型号去重；这些结论只代表此固定版本和该次请求。
- 修正流程图中可能误读为反馈循环的连线，SSE终点明确为浏览器。
- 链路B复核：compose_system_prompt未插入state_summary不代表最终模型缺少产品/历史。durable_node设置turn_context，ModelRouter经统一context层补齐产品、有效事实、原话和历史；真正的证据裁切发生在task_data生成阶段。
- 链路B复核：运行图的父块扩展在grade及补查之后，旧eval一轮入口顺序不同。评测共享search_round不等于覆盖完整线上编排。
- 链路B优先修改候选过早裁剪、充分性补查与两轮最终证据选择；改写、重排、父块等能力的收益须独立评测，不以开关全部开启代替方案。
- 历史改写100%是较早模型报告；较新报告已为75%/75%/62%。检索0次补查触发不能证明改写好坏。旧父块标记覆盖、无知识返回命中及文档命中率不能当作回答正确率或跨SKU泄漏。
