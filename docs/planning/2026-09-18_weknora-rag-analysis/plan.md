# WeKnora RAG 源码与本地案例分析

## 目标
结合 Tencent/WeKnora 源码、本地运行版本和指定会话，说明数据入库、检索、上下文组装、回答生成及架构设计；提供 ASCII 图和可核验的源码引用。

## 范围
- 只读检查运行服务、会话、知识库与相关数据库记录。
- 不发起新对话或真实模型测试，不改业务实现。
- 区分 WeKnora 原生问答与 anker-haike 检索接入链路。

## 阶段
1. 确认运行版本、源码位置和案例数据。
2. 阅读固定版本源码，追踪入库与问答链路。
3. 将真实会话、知识片段和接入代码映射到架构。
4. 产出分析文档、ASCII 图、限制与证据索引。
