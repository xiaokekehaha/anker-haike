需要先对齐当前有效代码、配置和数据库迁移，再构建部署并完成一条真实会话冒烟。不能因容器 healthy 或 /health 返回 200 判定业务可用。本轮仅核查，未修改配置、重启、迁移或部署。

## 环境修复后的体验顺序
1. 新会话输入“我的 S1 Pro 吸力不正常”：检查安抚、候选产品确认与确认后的状态变化。
2. 新会话输入“我的 X10 Pro Omni 扫地机器人吸力变小，地上的灰吸不干净”：检查回复、检索过程与知识来源。当前不要求出现完整步骤闭环。
3. 点击“请求人工”：检查生成的问题摘要与复制结果；这不代表真实客服已接单。
4. 凭证流程在部署新版本且补齐可进入的升级路径后单独验收：上传测试图片或跳过，核对字段修改、确认、摘要中的事实与差异；使用演示凭证，真实 OCR 单列。
5. 分步排障 34–36 完成后，再验“还没解决 → 下一步 → 解决了 → 完成”和多次失败升级。
