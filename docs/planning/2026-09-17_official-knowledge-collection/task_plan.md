## 边界

- 用户已授权公开资料采集及项目知识库写入；不发布业务应用、不提交代码。
- 首批优先现有目录内产品的操作与排障资料，不把地区售后政策直接编为自动办理规则。
- 与演示资料用独立文档 ID 和来源字段区分；不覆盖其他会话的业务改动、不清库。
- 仅抓公开页面，保留 URL、采集日期、型号与来源；不绕过登录或访问限制。
