# 官方资料是否存在 bad case

这里的 bad case 指材料本身存在缺失、歧义或不适用于目标产品，不等于系统回答失败，更不等于主办方故意设坑。目前没有官方说明其刻意设置陷阱。

| 资料 | 证据及判断 | 系统应如何处理 |
| --- | --- | --- |
| rv-0371 / T40 | 原文第二条 “Suggested troubleshooting steps can be found at:” 后无链接或步骤。确认资料不完整。 | 可以解释已知内容，但应说明缺少后续步骤；不虚构操作，不自动判硬件故障。 |
| rv-0073 / T40；rv-0061 / T32 | 两条源文均有实际 URL，卡片分别存于 media 的 link/image。第十轮核对完整事件后确认没有丢链接。 | 不能只读 instruction 就误判资料缺失；操作与材料混段仍属于系统编译问题。 |
| T13 的 5116 | 当前官方 QA 错误码索引无对应条目。确认该 QA 集覆盖缺口，不能由此断言所有其他手册也没有。 | 不套用邻近错误码；真实交接到人工即该轮边界。 |
| T50 的 does work | 字面说左侧能工作，后续目标不明。属于原话歧义，不足以证明是拼写错误。 | 保留原文，合理澄清另一侧或具体需求；不能擅自改成不能工作。 |
| rv-0138 / T23 | 答案尾部夹带 Applicable Models、Applicable Error Codes、Core Symptoms。内容混合索引信息。 | 可用于召回与适用性判断，不应成为客户操作正文。 |
| bp-0111 / T51 | 乳泵条目出现 speaker cover 等部件名称；是否笔误需产品资料复核。当前只能标为可疑，不判已证实错误。 | 保留来源并列入人工核对；不发明替代名称。 |
| T48 的绿灯 | 当前召回证据只让读手册，没有绿灯含义；这是检索结果的覆盖限制。 | 如实说明目前证据不足；继续核对手册后才能区分漏召回与资料缺失。 |
| 商品简称与长销售标题 | 早先抽样 T4 的 eufy X10 Pro Omni 与长标题中的同型号一致。不是 bad case；当前全量对应 T3，不能混用编号。 | 用型号、SKU、订单与包裹交叉核对，不要求销售标题逐字相等。 |
| 正常提醒、抱怨、操作与材料混在一段 | T35 是正常回充说明；T58 只有抱怨；T19/T26 同段有操作和问句/材料。是真实客服输入常见结构。 | 修系统的状态与内容类型，不能把格式不规整都归因于官方。 |

系统缺陷已证实：模型不可用仍选检索第一名、关闭案件却说等待、充电盒与内部设备混淆、没有原文请求仍加查询、用 cleaned 匹配 cleaning task 而跳过未做操作。这些都有通用边界，应修系统；官方资料是否存在其他缺陷不影响这一结论。
