# L3 本地开发与演示

所有政策与订单均为演示数据，真实 SOP 到手后替换 config/policy。P0 自动写动作仅 replacement.create；维修、退款、地址变更交由人工。

## 启动与校验

```sh
make db-upgrade
make seed WHAT=backends
cd orchestrator
uv run haike-db check
uv run haike-policy lint
uv run haike-eval all
uv run uvicorn app.main:app --host 127.0.0.1 --port 8002
```

前端构建：`npm --prefix frontend run build`，随后打开 http://127.0.0.1:8002；审批台 http://127.0.0.1:8002/admin/approvals。
纯确定性验证可加 HAIKE_LLM=off；真实演示使用 .env 里的 domestic 模型。数据库为 haike，其他数据库不写入。

## 演示路径

- A4：输入“查物流 DEMO-X10-001”，应返回模拟来源、状态和更新时间；无需确认产品。
- A5：X10 Pro Omni 排障未解决 → 核验 DEMO-X10-001 订单 → 确认使用地 CN → 选择换货 → 回执与跟踪状态 → 评分。创建申请不等于结案。
- A6：DEMO-UK-005 订单购买地 UK、使用地 DE → 人工审核队列；填写审批意见和覆盖理由后批准，审核决定回到原会话；编辑方案会要求用户再次确认。
- A7：输入“X10 Pro Omni 不吸了，另外换货单 DEMO-X10-001 发出去了吗”，完成排障后自动接续物流查询；等待卡片时可插入查询。
- A8：连续表达不满、愤怒和投诉；检查人工协助提示、案件高优先级，无补偿金额承诺。
- A9：真实滚刷缠绕图应产生结构化定位；模糊图片可补拍或跳过，连续两次补拍仍不可用后转人工。真实图片集尚待补齐，结构测试不能代替模型准确率。

## 审批、幂等与故障

管理台“售后审批”支持批准、拒绝、要求补充信息。并发审批以 revision 乐观锁返回 409；投递失败后保留决定，可点击重试。R4、安全限制、未核验订单、未确认方案不会被政策特批绕过。
执行幂等键绑定案件、动作和方案；业务后端再按订单与服务类型幂等。可恢复失败显示“办理失败，可重试”及“重试原申请”卡；确认后复用原幂等键。若政策依据改变，会先重新确认/审核，不能沿用旧授权直接重试。超时可恢复一次过期执行租约，后台处于 running 时不会重复并发提交。
故障注入配置 config/backends_mock.yaml，DEMO-FAIL-001/002/003 分别用于 timeout/unavailable/conflict；变更故障配置后重启当前服务。
人工结案需登录代理后的管理员身份；执行中案件应先核实回执。用户结案需要外部 shipped/completed/delivered 与明确确认。评分不影响状态；结案后可重开。

## 指标与保留

指标按(session_id, issue_id)去重。HTTP 表单 evaluation_source=smoke 或 replay 剔除测试，回放模式自动标记 replay。无评分/无意图标注显示暂无数据。未结案案件保留会话恢复能力；闭案 30 天后允许普通 TTL 清理；用户主动删除时匿名化案件和审计原文。

## 发布限制

本轮仅本地开发验证，Docker 8000 可能仍运行旧镜像。不得把 8002 的验证结果当作已发布镜像验收。冻结前执行 contracts-check、类型检查、前后端测试、授权评测、回放包重新录制、真实图片 bake-off；记录未完成项，不伪造录屏或模型识别率。

回放格式现为 3，旧格式包不能加载，必须重新录制。上下文运行 ID 与事实引用按结构映射到回放会话，用户原话、业务编号及业务日期保持原值。回放重现录制时点的答案，不能作为实时模型回答缓存；时间类答案需要明确按录制时点理解。
